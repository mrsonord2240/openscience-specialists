# Candidates not built — what each needs (2026-09-10)

Gate numbers refer to `THRESHOLD.md`. "Unaudited" means the Skill ships without a skill-auditor
report, so it cannot pass gate 2 regardless of quality. 325 of the 604 local Skills have no
`eval_report`; 183 of those carry only a backfilled `*_audit_result_v2.json`, which is not counted
(THRESHOLD.md gate 2). Most near-misses below are blocked on real audits, not on missing content.
