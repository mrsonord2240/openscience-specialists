# Security

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/mrsonord2240/openscience-specialists/security/advisories/new)
on this repository. Do not open a public issue.

Published release descriptors and Release assets are immutable. A fix ships as a new version,
not an edit to a published one.

If the signing key is compromised, a new key ID is published and announced in the
[README](README.md). Users must re-review the source before continuing to trust it.
